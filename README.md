# Python Fundamentals for Cybersecurity
This repository contains beginner-level Python exercises developed during my initial studies
in programming and cybersecurity fundamentals.

The focus of this project is to build a solid foundation in Python by practising core concepts
such as input handling, conditional logic, loops, and basic problem-solving, including simple
scenarios inspired by cybersecurity contexts.

---

## Topics Covered
- Python syntax and basic data types
- User input and output
- Arithmetic operations
- Conditional statements (`if`, `elif`, `else`)
- Logical operators (`and`, `or`)
- Loops (`for`, `while`)
- Simple validation and decision-making logic

---

## Repository Structure
- input_output/
- arithmetic_calculations/
- conditionals/
- logical_operators/
- loops/
- basic_security_scenarios/

---

## Folder Overview
### `input_output`
Basic interaction with an user using input and output operations.
- Personal introduction (name and age)
- Username generation using string manipulation
- Equality check between user inputs

---
### `arithmetic_calculations`
Scripts focused on numeric operations and calculations.
- Sum calculator
- Average calculator
- Rectangle area and perimeter calculation
- BMI (Body Mass Index) calculator with classification

---
### `conditionals`
Decision-making logic using conditional statements.
- Age verification
- Number comparison
- Student grading system with validation
- Even or odd number checker
- Triangle validation and classification

---
### `logical_operators`
Use of logical operators to combine multiple conditions.
- Simple access control system
- Discount calculation logic
- Game access validation
- Loan approval decision system

---
### `loops`
Iteration using `for` and `while`.
- Countdown simulation
- Access attempt simulation

---
### `basic_security_scenarios`
Introductory security-inspired scenarios used to practise Python logic.
- Iteration over common network ports
- Character-by-character analysis of a suspicious string
- ATM withdrawal simulation with validation rules

---

## Disclaimer
All scripts in this repository are created **for educational purposes only**.

They do not include real credentials, sensitive data, or active exploitation techniques.
Any cybersecurity-related references are purely illustrative and intended to support
learning Python fundamentals.

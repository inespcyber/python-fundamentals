# Python Fundamentals for Cybersecurity
This repository contains beginner-level Python exercises developed during my initial studies
in programming and cybersecurity fundamentals.

The focus of this project is to build a solid foundation in Python by practising core concepts
such as input handling, conditional logic, loops, and basic problem-solving, including simple
scenarios inspired by cybersecurity contexts.

---

## Topics Covered
- Python syntax and basic data types
- User input and output
- Arithmetic operations
- Conditional statements (`if`, `elif`, `else`)
- Logical operators (`and`, `or`)
- Loops (`for`, `while`)
- Simple validation and decision-making logic
